# SERVING dependencies only.
#
# The list is this short on purpose. Two deployment failures drove it there,
# and both had the same root cause -- shipping libraries that only the BUILD
# needs:
#
#   pandas        excluded. Serving reads a NumPy+JSON catalog bundle, not
#                 parquet (src/recsys/catalog_view.py).           -55MB
#
#   scikit-learn  excluded. The trained trees and the TF-IDF/SVD encoder are
#   scipy         exported to plain arrays at build time
#   joblib        (src/recsys/serving/), so nothing is unpickled at
#                 request time.                                   -200MB
#
# The size mattered, but portability mattered more. A pickled
# HistGradientBoostingClassifier references a Cython class whose __module__ is
# the bare name "_loss", so unpickling needs a top-level `import _loss` to
# resolve. That works locally by accident of import order and did not work in
# the deployed function, which failed with
#
#     ModuleNotFoundError: No module named '_loss'
#
# Pinning versions did not fix it, because the version was never the cause.
# Exporting the trees removed the reference and the dependency together.
#
# tests/test_serving_deps.py enforces this list: it blocks every excluded
# library and then runs a real recommendation and a real search.
#
# The BUILD pipeline needs all of them -- see requirements-build.txt.
# ---------------------------------------------------------------------------
